Нейро-Сёма — офлайн без сервера

ГЛАВНЫЙ ФАЙЛ:
  neuro-sema.html — всё приложение в одном файле, открывается двойным щелчком

ЗАПУСК:
  1) Откройте neuro-sema.html
     или
  2) Запустите ОТКРЫТЬ.bat

АКТУАЛЬНЫЕ ВОЗМОЖНОСТИ:
  - Поиск на стартовой странице (результаты появляются ниже строки поиска)
  - Фильтры по системам (SFA, Pega, ClaimCRM, AlfaClever и др.)
  - Пагинация результатов (4 компании на страницу)
  - Кнопка "Свернуть/Показать результаты"
  - Выбор формата открытия карточки:
      * Полный отчёт
      * Предложения
      * Риски
  - Возврат из карточки "Назад" сохраняет параметры поиска и страницу результатов

РАЗДЕЛЫ КАРТОЧКИ КОМПАНИИ:
  - Полный отчёт: реквизиты, ОКВЭД, фин. показатели, контакты, сводка
  - Предложения: оферты, факторинг, льготные программы, ВЭД/ФТС, лизинг и т.д.
  - Риски: БКИ, РНО, 115-ФЗ, жалобы, санкционные ограничения, банкротство
